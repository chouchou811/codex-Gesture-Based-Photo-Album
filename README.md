# 手势点击 Demo

这是一个纯前端 demo：摄像头识别手部，绚烂星空持续移动；当拇指和食指闭合时，星空暂停并随机显示一张照片。

## 本地运行

在当前目录启动静态服务：

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8123
```

浏览器会请求摄像头权限。允许后，把手放在画面中：

- 星星会持续移动
- 拇指和食指闭合：暂停星星并随机显示照片
- 张开手：恢复等待下一次闭合

## 给别人使用

可以给别人用，但要满足这些条件：

- 页面必须通过 `https://` 访问，或者在本机 `localhost/127.0.0.1` 访问，否则大多数浏览器不会开放摄像头权限。
- 使用者需要允许摄像头权限。
- 目前只能点击网页内部按钮，不能控制系统鼠标。
- 依赖 MediaPipe CDN，联网才能加载手部识别模型。

适合部署到 GitHub Pages、Vercel、Netlify 或自己的 HTTPS 网站。
